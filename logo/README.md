# labelbee logo

The 8-bit bee (17 x 15 dots), drawn 2026-10-18, with the wordmark "label**bee**"
(Barlow Condensed Bold, "bee" on honey yellow).

| File | Use |
|---|---|
| `labelbee-bee.svg` | screen: honey #f2b705 body, white wings, #17140f outline (also `www/favicon.svg`) |
| `labelbee-bee-dark.svg` | dark backgrounds: light outline, wings translucent (also `www/favicon-dark.svg`) |
| `labelbee-bee-1bit.svg` | print: black dots only, for the label printer (on yellow tape it looks like the screen version) |

Scale only by whole numbers (or keep `shape-rendering: crispEdges`), so the dots stay square.
